# Split buttons

Split buttons open a menu to give people more options related to an action

## Overview

-   Use to show an action with a menu of related actions
-   Same size range as buttons and icon buttons: XS, S, M, L, XL

## M3 Expressive update

**May 2025**

The split button has a separate menu button that spins and changes shape when activated. It can be used alongside other buttons of the same size. [More on M3 Expressive](../../blog/building-with-m3-expressive.md)

New component added to catalog.

Sizes:

-   Extra small
-   Small
-   Medium
-   Large
-   Extra large

Color styles:

-   Elevated
-   Filled
-   Tonal
-   Outlined
