# Using Block Patterns with Material Design for WordPress

Plus other new features introduced in version 0.3.0

![Image](<https://lh3.googleusercontent.com/vrwte8PxAxg03-ctZYmdS8w3LD-S6BxgzOeVulzl8VckEsrsKZm3eL6Mv0uxG02jEPOHWHpCwmh83Khx8B6cIVGEceAEha9qj2j3WSYX26jLyI9Qw60>)

Published: 2022-01-05T13:00:00

#### You can learn more about the Material Design for WordPress plugin in [this blog post](https://material.io/blog/material-design-wordpress-plugin).

With the [0.3.0 update](https://github.com/material-components/material-design-for-wordpress/releases/tag/0.3.0) to the Material Design for WordPress plugin, you can now use [Block Patterns](https://wordpress.com/support/block-pattern/) to compose beautiful layouts and reusable sections.

## What are Block Patterns?

[Block Patterns](https://wordpress.com/support/block-pattern/) are new components in WordPress that allow you to quickly build with templates for common layouts.

You can combine blocks to create complex and beautiful pages.

## How to add a Block Pattern

Using the [Gutenberg WordPress Editor](https://wordpress.org/gutenberg/), you can add a new block pattern using the add icon on the toolbar, or from the editor.

![screenshot of the add icon in WordPress](<https://lh3.googleusercontent.com/LEPQxYEjntgi8PDyx5eSymA8FIepMus3j2Z6zxsvMBKKNV5m2ebpHwmKMm4YOPH3D6eD0jmv3sz74q9B1bmKWdN93w3YG0bo33N17Xkiwut7t6k5YQ>)

Selecting the “Patterns” tab and choosing “Material Design” in the dropdown will filter all the new Material Block Patterns.

![screenshot of the WordPress editor](<https://lh3.googleusercontent.com/rqPIaq5HLhzsNMQg_A8s8aUpCe-v-khdwDIrtprRbn3qAaTaC4RIqwGheuxY-aaQmaY9YvuG_dkTT-y0erBkgQJm5GDDP1173yMvYV9mdzTHOzkj1IU>)

You can select or drag a pattern from the list to the editor and start to customize the content.

![screenshot of a block template](<https://lh3.googleusercontent.com/URrPuatkidhWuax0KKBQSVdifd0UdMCltvgqSItw6mpbIjE-NyQu6OZ4o1OhFmNu-2RfPlm9OkiVOV--X4VJqV1luBvNxKZePaURWCWxuglqaYwbMGE>)

Templates will automatically include placeholder text where necessary, which you can replace with your own content.

![screenshot of a block template](<https://lh3.googleusercontent.com/f7cRsNeHX9kRfcLZhVs2NP_aATpvsdxMTBikvsrizuaBDyFzqCzHZ20PQfHbglmN58Gaj9Rwwd7M_-Nbm5JY3Al2IIpISnjDBjddequIDcAGk3h5mIs>)

## Theming

Start by changing the starter style in the  customizer (wp-admin > Appearance > Customize > Material Design Options).

![screenshot of theme options within the plugin](<https://lh3.googleusercontent.com/ykFIGvwHx7itcLRR-nMJOj7dfG3hAZd3xD8sXB8y1AQMGyYURBIBzp52dP27Wqhc-5Bk3dS_-gkgyQbTQAYvobWjAYIzNoDeE-eUt3ArBEkud6Ob9J7y>)

Now navigate to any page and start editing in the Gutenberg editor.

![a themed edit button](<https://lh3.googleusercontent.com/hooa7W6JDn_VMZHPDKkqYkzGR2j0kTfXSEUP0Uk__rSarM5P5GzD2hRibTpJbvdaX8F0zN7p36dcUDXpLVBM2y1wIVrwi6Rxgy1M-TiRXOcwc6HbOtA>)

With the Crane theme active all the Material Block Patterns will show a preview of the correct theme.

![a themed example screenshot](<https://lh3.googleusercontent.com/oAw_omytiHjod4h1vDpQqQOT3TcXE4HwdhvSpNQ8ayvXKBoD4r1XQ9-E56XAu72Wn3hnK2RbNYWHEmLGO1tUZRelnKkctXLT7RtlW6eUAt0d7oLQkJEv>)

By adding a block pattern to the page you can start to edit any component that makes up the pattern just like Material Blocks.

Both Material Block Patterns and Material Blocks can be themed and customized to the design of your choice.

There are a lot of patterns to choose from. Here’s a full list:

-   Call to action
-   Call to action + benefit
-   Contact form
-   Features + CTA
-   Numbers
-   Hero section
-   Hero section + image
-   Latest posts
-   Highlights
-   Feature list
-   Logos
-   Media grid
-   Single feature
-   Single feature extended
-   Pricing
-   If you have an idea for a new block pattern you can discuss it on the [Github repo](https://github.com/material-components/material-design-for-wordpress/discussions/157)!
