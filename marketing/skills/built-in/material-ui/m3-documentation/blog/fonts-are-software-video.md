# Video: Fonts are software

Catch up on Google Fonts' talk at Figma Config 2023

![Splitscreen: tobias and a screenshot of text in an app](<https://lh3.googleusercontent.com/UZDpLpdaA00MuMc0cBiRzQTG3zvUR-ZMHyI7LALYCBzw3ZA7hRxnb-bwy4GZS7yqJhAxbIBWtQMQiAO4saj2W2YgfA-LAyFU26Zu3ilF_4l_SB3YOTk>)

Published: 2023-08-24T13:00:00

If you were a web designer in the early days of the Internet, you might remember that there were few “web safe” typefaces, such as Arial and Georgia. As a result, many websites looked similar. To use a new typeface, you had to embed small Flash files for each heading in your layout.

Now with [web fonts](https://fonts.google.com/knowledge/glossary/web_font) and [variable fonts](https://fonts.google.com/knowledge/using_variable_fonts_on_the_web), the situation has changed dramatically. Designers have many more typeface choices to customize their websites and brands.

Here are some of the ways that variable fonts are changing type:

-   They allow designers to create more nuanced and expressive typography with different weights, widths, and other axes.
-   They can improve the performance of web pages by reducing the number of font files that need to be loaded.

Tobias Kunisch went from being a webmaster at Google in 2010 to being one of the co-founders of Google Fonts, whose mission is to provide open source fonts without charge. Kunisch spoke at the [Figma Config Conference](https://config.figma.com/) in June 2023 in San Francisco about how fonts are like software and how they open up new digital design possibilities.
