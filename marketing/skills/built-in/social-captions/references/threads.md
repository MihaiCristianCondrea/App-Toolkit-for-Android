# Threads post

Part of [`social-captions`](../SKILL.md). The file `captions/threads.txt` holds only the post.

## Template

```text
<One or two conversational sentences: what you made and why.>

<Link>
```

## Rules

- 500 characters per post; one link per post is clickable.
- Threads uses one topic tag per post, not hashtags: leave tags out of the text and pick the topic when posting.
- Conversational, first person. A question at the end invites replies.

## Example (Android Insider trailer)

```text
Made a 33 second trailer for Android Insider: Android news, guides with the real Kotlin, and Studio Bot for the questions after. What do you use to keep up with Android?

https://play.google.com/store/apps/details?id=com.mihaicristiancondrea.android.apps.androidstudiotutorials
```
