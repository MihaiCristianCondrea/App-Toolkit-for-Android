# X post

Part of [`social-captions`](../SKILL.md). The file `captions/x.txt` holds only the post.

## Template

```text
<One or two sentences: the hook and what the product does.>

https://play.google.com/store/apps/details?id=<packageId>

<1 to 5 hashtags>
```

## Rules

- 280 characters in total; any link counts as 23.
- Up to 5 hashtags (2 or 3 read best), counted in the 280. Attach the video or the strongest image.
- For a thread, write one file per post as `x.txt`, `x-2.txt`, ...; each post must read on its own.
