# LinkedIn post

Part of [`social-captions`](../SKILL.md). The file `captions/linkedin.txt` holds only the post.

## Template

```text
<A first line that states the problem or the news plainly.>

<2 or 3 short paragraphs: what you built, for whom, and one concrete detail of how it works or what you learned building it.>

<A plain call to action: try it, read it, or tell me what you think.>

<Link>

<3 to 5 hashtags>
```

## Rules

- About 210 characters show before "see more": the first line carries the post.
- Up to 3,000 characters; 600 to 1,200 reads best. Short paragraphs, one blank line between them.
- Write in the first person, as the developer who built it. No hype, no "thrilled to announce".
- Links in the post are fine but reduce reach a little; keep one.
- 3 to 5 hashtags, professional topics the audience follows.

## Example (Android Insider trailer)

```text

The trailer shows the whole path in 33 seconds. If you build for Android, I would like to hear what you think.

https://play.google.com/store/apps/details?id=com.mihaicristiancondrea.android.apps.androidstudiotutorials

#AndroidDevelopment #JetpackCompose #Kotlin #DeveloperTools
```
