# Research

Material that informs marketing and the redesign but is not published.

## analytics/

Six CSV exports from Google Analytics for Firebase (property `app-toolkit-for-android`), covering July 27 to October 24,
2026, added to the repository on October 26, 2026:

| File | Report |
| --- | --- |
| `Audiences_Audience_name.csv` | Users, sessions and revenue for All Users |
| `Firebase_overview.csv` | Active users over 1, 7 and 30 days |
| `Generate_leads_overview.csv` | New users per week |
| `Tech_overview.csv` | Active users by platform |
| `Tech_details_Browser.csv` | Engagement and events |
| `User_acquisition_First_user_primary_channel_group_(Default_Channel_Group).csv` | New users by acquisition channel |

They are reported context for one period, not proof of what to build or claim. Do not quote their numbers in store
copy, captions or campaigns. A new export goes beside them with its own date range; these are not edited.
